01 · 문제 정의

러닝화 쇼핑이 왜 어려운가

가격, 쿠션감, 발볼, 드롭, 안정성, 사용 목적… 고려할 요소가 너무 많다. 기존 AI와 쇼핑 경험에는 3가지 구조적 문제가 있다.

💬

기존 AI 채팅 답변 예시

마라톤 훈련과 주 40km 러닝 패턴을 고려하면 Hoka Clifton 10, New Balance 1080 v14, Brooks Ghost Max 세 가지가 적합합니다. Clifton 10은 MaxCush 폼으로 장거리에 이상적이며 5mm 드롭으로… 1080은 Fresh Foam X로 안정성이 높고 4E 발볼 옵션이 있어… Ghost Max는 균형형으로…

  • Clifton 10: 쿠션 우수 / 장거리
  • 1080 v14: 안정성 / 발볼 넓음
  • Ghost Max: 균형형 / 데일리

↑ 대화가 10개쯤 되면 이 내용은 스크롤 위로 사라진다...

⚠️

기존 쇼핑 경험의 3가지 문제

🌊

1. 정보가 위로 밀려 사라진다

대화가 길어질수록 내 조건, 후보 목록, 비교 결과가 스크롤 위로 밀려난다. "다시 정리해줘"를 반복 요청해야 한다.

🤖

2. 범용 AI는 쇼핑에 특화되지 않았다

불필요한 설명과 반복 대화가 늘어난다. 발볼·드롭·쿠션 등 구매 결정에 필요한 정보만 빠르게 구조화하지 못한다.

🗂️

3. AI와 쇼핑 페이지가 분리돼 있다

실제 구매는 Running Room, Hoka, NB 사이트에서 하는데 AI는 다른 탭에 있다. 상품 정보를 직접 복사·붙여넣어야 한다.

💡 그래서 필요한 것
📌 쇼핑 상태를 계속 구조화
🛒 쇼핑 페이지 위에서 바로 작동
🎯 러닝화 전용 — 발볼·드롭·쿠션 중심

04 · 사용자 페르소나

누구를 위한 도구인가

"아무 신발이나 사는 사람"이 아니라, 다음 러닝화를 신중하게 고르고 싶은 러너를 위한 도구다.

🛒
Primary User · 핵심 사용자

"정보 과부하" 러너

"Reddit, 유튜브 다 봤는데 오히려 더 헷갈려요."

목표

  • 마라톤 훈련에 맞는 신발을 신중하게 고르고 싶다
  • 여러 후보를 명확한 기준으로 비교하고 싶다
  • "나에게 맞는지" 즉시 판단받고 싶다

페인 포인트

  • 리뷰가 너무 많아 오히려 결정이 더 어렵다
  • AI 채팅 정보가 스크롤 위로 밀려 사라진다
  • 쇼핑 페이지와 AI 탭을 번갈아 오가야 한다

필요한 것

  • 조건·후보·탈락 이유가 고정된 패널에 남는 것
  • 지금 보고 있는 신발의 적합도 즉시 판단
  • 최종 구매 결정 리포트
🏃
Secondary User · 첫 마라톤 준비자

"첫 마라톤" 준비 러너

"레이스화 vs 훈련화 차이도 모르겠고, 발볼도 애매해요."

목표

  • 첫 풀/하프 마라톤 훈련화를 제대로 고르고 싶다
  • 발볼·쿠션·드롭 개념을 나에게 맞게 이해하고 싶다
  • 기존에 신발 때문에 다쳤던 경험을 반복하지 않고 싶다

페인 포인트

  • 러닝화 용어(드롭, 스택 하이트)가 낯설어 비교가 어렵다
  • 발볼 때문에 선택 실패한 경험이 있다
  • 정보는 많지만 "내 케이스"에 맞는 답을 못 찾겠다

필요한 것

  • 러너 프로필 기반 맞춤 분석 — 내 발볼·목적 반영
  • 비교 기준을 명확하게 설명해주는 구조화된 UI
  • 구매 전 확인 체크리스트 (사이즈·반품 정책 포함)

07 · 디자인 원칙

4가지 설계 원칙

AI 러닝화 Decision Workspace의 UX 품질을 결정하는 핵심 원칙입니다.

👁️

스캔 가능성 우선 (Scannability First)

고대비 타이포그래피와 명확한 계층 구조로 3초 안에 핵심 정보(적합도·리스크·순위) 파악 가능하도록 설계

📌

고정 패널 실시간 업데이트

대화 영역은 스크롤되어도 결정 패널(조건·후보·탈락 이유)은 항상 최신 상태를 유지. 사용자는 처음부터 다시 설명할 필요 없음

⚖️

가능성 중심 표현 (Trust Indicators)

"맞다/안 맞다" 단정 대신 항상 "가능성"과 "확인해야 할 리스크" 중심으로 표현. 핏은 개인차가 크기 때문에 실착 권장과 함께 제공

📱

반응형 레이아웃 (Responsive Layouts)

Chrome 사이드바·전체 페이지 모두에서 작동. 사이드바 모드에서도 핵심 정보(적합도·후보 순위)를 한눈에 파악 가능

08 · 성공 지표

무엇으로 성공을 측정하나

초기 성공 기준은 "추천을 받았다"가 아니라 더 빠르게 구매 결정을 내렸는가다.

⏱️

Time-to-Decision (TTD)

상품 비교에 걸리는 시간. 기존 AI 채팅 대비 단축 여부. 목표: 40% 단축

🎯

후보 감소율

사용자가 후보를 몇 개까지 줄였는가. 5개+ 에서 2–3개로 압축 여부. 목표: 세션당 60%+

📋

최종 리포트 생성률

"최종 정리해줘" 입력 후 구매 결정 리포트를 생성한 비율. 목표: 세션당 60%+

09 · 전략적 로드맵

3단계 확장 계획

러닝화 전용 MVP에서 시작해 범용 쇼핑 Decision Workspace로 확장합니다.

👟
MVP · 현재

러너 프로필 + 현재 페이지 분석

러닝화 전용 Decision Workspace. Running Room, Hoka, NB 3개 사이트 지원. 러너 프로필 생성 · 상품 분석 · 후보 비교 · 최종 리포트 4가지 MVP 기능 완성.

🏆
Beta · 다음 단계

후보 비교 패널 + 최종 구매 리포트 고도화

지원 사이트 확장 (Amazon, Nike, Asics, Brooks, On). 사이즈 추천 · 반품 정책 자동 확인. PDF 내보내기 · 공유 기능 추가.

🌐
Scale · 장기 목표

범용 쇼핑 Decision Workspace

러닝화에서 검증된 "고정 결정 패널 + 구조화 분석" 모델을 다른 고관여 쇼핑 카테고리(자전거 · 아웃도어 장비 · 노트북)로 확장.
